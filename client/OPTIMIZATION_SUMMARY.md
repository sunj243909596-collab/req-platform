## 📊 性能优化

1. **动画性能**
   - 使用 transform 替代 position
   - GPU 加速的 CSS 动画
   - 合理的动画延迟避免卡顿

2. **滚动性能**
   - 使用 IntersectionObserver（motion/react 内置）
   - 动画只触发一次（once: true）
   - 合理的视口边距

3. **渲染优化**
   - AnimatePresence 避免不必要的 DOM
   - 条件渲染减少组件树
